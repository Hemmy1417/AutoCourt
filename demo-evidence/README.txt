Demo documents for AutoCourt.

Drag any of these into "Add evidence" on an assessment:

  service-invoice.txt     the seller's own paperwork (first-party)
  vehicle-history.txt     a history pull that mentions a wing refinish
  rolled-back-listing.txt a LATER document with a LOWER odometer reading

Upload the invoice and then the rolled-back listing, add a typed
odometer row to each (2026-03-07 / 87432 and 2026-05-01 / 62000), and
the contract recomputes the mileage conflict itself — the report
headlines POSSIBLE ODOMETER ROLLBACK without any model being asked to
decide it.
